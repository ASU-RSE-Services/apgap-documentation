## **Release Notes v1.6.0 (2026-07-20)**

### **Bug Fixes**

* **Inactive Labs Restrictions:** Blocked file metadata edits, dataset creation, and batch uploads on inactive labs. *([Ticket \#181](https://github.com/azpathogens/apgap-development-tickets/issues/181))*  
* **Access Approver Syncing:** Re-sync access request approvers automatically when a lab director changes.  
* **Worker Tasks Fix:** Registered the rename-notification task so the worker successfully runs it. *([Ticket \#183](https://github.com/azpathogens/apgap-development-tickets/issues/183))*  
* **Dataset Management:** Restored the dataset deletion action. *([Ticket \#100](https://github.com/azpathogens/apgap-development-tickets/issues/100))*  
* **Queue Visibility:** Now displaying "pending archive" status on PRIMARY sequences and scoping director queues properly. *([Ticket \#171](https://github.com/azpathogens/apgap-development-tickets/issues/171))*


### **Features**

* **Enhanced Navigation & Filtering:**  
  * Added a dedicated **Data Explorer**. *([Ticket \#175](https://github.com/azpathogens/apgap-development-tickets/issues/175))*  
  * Added pathogen and source type columns to data catalogue. *([Ticket \#184](https://github.com/azpathogens/apgap-development-tickets/issues/184))*  
  * Enabled **Bulk Dataset Creation** using all files matching a specific filter. *([Ticket \#188](https://github.com/azpathogens/apgap-development-tickets/issues/188))*  
  * Enabled cross-page selection for lab sequences.  
* **Metadata & List Management:**  
  * Added **Metadata Corrections** support and attached correction history directly to file metadata. *([Ticket \#190](https://github.com/azpathogens/apgap-development-tickets/issues/190))*  
  * Allowed the reuse of existing option lists via link or copy. *([Ticket \#182](https://github.com/azpathogens/apgap-development-tickets/issues/182))*  
* **Notifications & Communication:**  
  * Added functional action links and comments directly into notification emails. *([Ticket \#180](https://github.com/azpathogens/apgap-development-tickets/issues/180))*  
  * Added the original upload time to failed upload notifications. *([Ticket \#194](https://github.com/azpathogens/apgap-development-tickets/issues/194))*  
  * Added email reminders. *([Ticket \#163](https://github.com/azpathogens/apgap-development-tickets/issues/163))*  
* **Workflows & Approvals:**  
  * Added tiered access permissions to draft sequences for lab collaborators.  
  * Introduced lab-level dataset auto-approval grants. *([Ticket \#164](https://github.com/azpathogens/apgap-development-tickets/issues/164))*  
  * Allowed approvers to modify a requested metadata option value directly upon approval. *([Ticket \#206](https://github.com/azpathogens/apgap-development-tickets/issues/206))*  
  * Lab directors can view file deletions in their labs. *([Ticket \#179](https://github.com/azpathogens/apgap-development-tickets/issues/179))*  
* **Platform Administration:**  
  * New view for platform admins to see all Google Cloud Project (GCP) IDs for labs and projects. *([Ticket \#186](https://github.com/azpathogens/apgap-development-tickets/issues/186))*  
  * Added a platform-admin button to manually re-sync notebook access permissions. *([Ticket \#195](https://github.com/azpathogens/apgap-development-tickets/issues/195))*

### **Refactoring**

* Optimized operations by batching metadata corrections into a single asynchronous task.

### **Chores**

* Retired the ashb id template. *([Ticket \#157](https://github.com/azpathogens/apgap-development-tickets/issues/157))*

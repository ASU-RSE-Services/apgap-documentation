## **Release Notes v1.7.0 (2026-07-24)**

### **New Features & Enhancements**

* **Top Navigation Notifications:** Added an in-app notification icon to the top header to alert you to important activity ([Ticket \#216](https://www.google.com/search?q=https://github.com/azpathogens/apgap-development-tickets/issues/216)).  
* **Batch Upload Tracking:** Receive batched notifications when large batch file uploads finish or encounter processing failures ([Ticket \#215](https://www.google.com/search?q=https://github.com/azpathogens/apgap-development-tickets/issues/215)).  
* **Analytical Datasets:** Files that have been approved for a dataset are now available right upon approval ([Ticket \#217](https://github.com/azpathogens/apgap-development-tickets/issues/217), [Ticket \#227](https://github.com/azpathogens/apgap-development-tickets/issues/227), [Ticket \#228](https://github.com/azpathogens/apgap-development-tickets/issues/228)).  
* **Data Privacy (Metadata Redaction):** Added support for redacting sensitive metadata fields across the platform ([Ticket \#211](https://github.com/azpathogens/apgap-development-tickets/issues/211)).  
* **Improved Cloud Resource Naming:** Updated Google Cloud (GCP) project naming conventions for better organization across labs, projects, and principal investigators ([Ticket \#185](https://github.com/azpathogens/apgap-development-tickets/issues/185)).  
* **Pipelines**: Added a page to list pipelines available for use ([Ticket \#192](https://github.com/azpathogens/apgap-development-tickets/issues/192)) and updated BaseSpace pipeline link ([Ticket \#212](https://github.com/azpathogens/apgap-development-tickets/issues/212)).  
* **Sequence Filtering**: Sequences can now be filtered by their status ([Ticket \#177](https://github.com/azpathogens/apgap-development-tickets/issues/177)).  
* **User Interface**: The user interface is now scoped to a single lab rather than all labs a user has access to ([Ticket \#214](https://github.com/azpathogens/apgap-development-tickets/issues/214)).

### **Bug Fixes**

* **File Type Auto-Detection:** Fixed an issue where bulk uploads required manual file type classification; the system now infers the correct file format directly from the filename extension ([Ticket \#222](https://github.com/azpathogens/apgap-development-tickets/issues/222)).

### **Behind the Scenes (Maintenance & Tech Debt)**

* **Security & Dependency Updates:**  
  * Upgraded `django` from 5.0.10 to 5.1.15 ([Ticket \#223](https://www.google.com/search?q=https://github.com/azpathogens/apgap-development-tickets/issues/223)).  
  * Upgraded `pytest` from 8.3.4 to 9.1.1 ([Ticket \#224](https://www.google.com/search?q=https://github.com/azpathogens/apgap-development-tickets/issues/224)).  
* **API Cleanup:** Removed deprecated and unused Access Requests API endpoints.  
* **Test Reliability:** Improved testing suite execution by running dataset copy tasks synchronously during unit tests.
